# fullstack-craft

> Building the web from foundations to full-stack: 30+ practical modules spanning semantic HTML, modern CSS layouts, DOM scripting, node runtimes, and standalone vanilla web engines.

## 🚀 Overview

This repository documents an intensive, end-to-end full-stack web engineering journey. Every module is built with clean architectural invariants, zero AI boilerplate, high-contrast accessible design (WCAG AA compliant), and authentic interactive logic.

---

## 📂 Curriculum & Project Directory

### Phase 1: HTML & Semantic Foundations
- **`4.0 File Paths`**: Relative and absolute path resolution, directory traversals.
- **`4.3 HTML Porfolio Project`**: Multi-page portfolio showcasing early web works and resume markup.

### Phase 2: CSS Architecture, Flexbox & Grid Systems
- **`5.3 CSS Selectors`** & **`6.3 CSS Box Model`**: Specificity, cascading rules, border-box sizing calculations.
- **`6.4 Motivation Meme Project`**: High-impact typographical layout with custom borders and font framing.
- **`7.1 Combining Selectors`**, **`7.2 CSS Positioning`**, & **`7.3 CSS Flag Project`**: Static, relative, and absolute stacking contexts.
- **`8.0 CSS Display`**, **`8.1 CSS Float`**, **`8.3 Media Query`**, & **`8.4 Web Design Agency Project`**: Fluid layouts, responsive breakpoints, mobile navigation.
- **`9.0 Display Flex`**, **`9.1 Flex Direction`**, & **`5. 9.4 Flexbox Pricing Table Project`**: Multi-tier responsive pricing comparison cards.
- **`10.0 Display Grid`**, **`10.1 Grid Sizing`**, & **`10.2 Grid Placement`**: Two-dimensional grid layouts, template areas, and auto-fit tracks.
- **`11.0 Bootstrap Intro`** & **`11.2 Bootstrap Components`**: Component-driven UI development with Bootstrap grid and responsive navbars.

### Phase 3: DOM Manipulation, Events & Game Engines
- **`DOM Challenge Starting Files`** & **`DOM-amazon`**: Document tree traversal, element manipulation, and event delegation.
- **`Drum Kit Starting Files`**: Real-time keyboard and audio API binding with CSS keyframe animation triggers.
- **`Simon Game Challenge Starting Files`**: Memory sequence state engine, randomized level progression, and error state tracking.
- **`jquery`** & **`Class-Exercise`**: Rapid DOM traversal and event synthesis using jQuery.

### Phase 4: Node.js, NPM & Asynchronous Operations
- **`2.1 Using Node`**: Server-side JavaScript execution with the Node.js V8 runtime.
- **`2.2 Native Modules`**: Asynchronous filesystem read/write streaming (`fs.writeFile`, `fs.readFile`).
- **`2.3 NPM`**: Package management, dependency injection, and CommonJS/ESM module interop.
- **`2.4 QR Code Project`**: CLI utility with `inquirer` prompts, `qr-image` stream generation, and automated file persistence.

### Phase 5: Production-Ready Standalone Web Engines
- **`Calculator`**: Swiss tactile arithmetic engine with keyboard inputs, precision calculations, and high-contrast styling.
- **`Chess`**: Complete Chess engine featuring a Minimax AI opponent, alpha-beta pruning, and audio integration.
- **`01-Task-Master-Kanban`**: Multi-lane productivity Kanban board featuring native HTML5 drag-and-drop, schema-versioned localStorage persistence, and JSON export/import.
- **`02-Weather-Pulse`**: Real-time meteorological station powered by the Open-Meteo REST API, live GPS geolocation, 24-hr hourly breakdown, and offline caching.
- **`03-Markdown-Live-Studio`**: High-performance split-pane Markdown editor with a custom AST tokenizer, live metrics, and dual-format file export.
- **`server.js`**: Built-in zero-dependency Node.js HTTP server hosting the central Dev Hub on port 5000.

## 🛠️ Running Locally

1. **Clone the repository**:
   ```bash
   git clone https://github.com/Natnael-Dev/fullstack-craft.git
   cd fullstack-craft
   ```

2. **Start the central Development Hub**:
   ```bash
   node server.js
   ```

3. Open **`http://localhost:5000`** to launch and interact with all 30+ web applications.
